# موقع الاستعلام عن بيانات الطالب — مدرسة أبو القاسم الزهراوي

نظام بسيط للاستعلام عن بيانات الطالب (الصف والشعبة) بالاسم الثلاثي أو الكامل، مع دعم الكتابة بالصوت.
مبني بـ HTML و CSS و JavaScript فقط، بدون أي مكتبات خارجية أو قاعدة بيانات.

## الملفات

- `index.html` — هيكل الصفحة
- `style.css` — التنسيق (متجاوب بالكامل، RTL، خطوط Cairo/Tajawal)
- `script.js` — منطق البحث والتحقق والرسائل
- `data.js` — بصمات مشفرة لصيغ الأسماء الثلاثية والكاملة، دون أسماء مكشوفة
- `images/school-logo.png` — شعار المدرسة

## رفع المشروع إلى GitHub

```bash
cd alzahrawi-school-lookup
git init
git add .
git commit -m "الإصدار الأول: نظام الاستعلام عن بيانات الطالب"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/alzahrawi-school-lookup.git
git push -u origin main
```

## النشر

**GitHub Pages:**
Settings → Pages → Branch: `main` → Folder: `/root` → Save.
سيصبح الموقع متاحًا على: `https://<اسم-حسابك>.github.io/alzahrawi-school-lookup/`

**Render (Static Site):**
1. New → Static Site → اختر المستودع `alzahrawi-school-lookup`
2. Build Command: اتركه فارغًا
3. Publish Directory: `.`

## ملاحظات هامة قبل الاستخدام الفعلي

- يتضمن الإصدار بيانات 824 طالبًا موزعين على 22 شعبة للعام الدراسي 2026/2027.
- لا يحتوي `data.js` على أسماء الطلاب؛ بل على بصمات SHA-256 لصيغ البحث.
- يقبل النظام ثلاثة أجزاء على الأقل من الاسم مع المحافظة على ترتيبها، ويمكن حذف كلمة «بن».
- عند تطابق الاسم مع أكثر من طالب، يطلب النظام إضافة جزء آخر من الاسم.
- يعمل الإدخال الصوتي في المتصفحات التي تدعم Web Speech API، وقد يطلب المتصفح السماح باستخدام الميكروفون.
- البحث بالاسم وحده في موقع عام أقل حماية من نظام يعتمد على رقم تحقق إضافي.
- لا ترفع ملفات PDF الأصلية أو ملف الاستخراج الداخلي إلى المستودع العام.
- الحماية الأقوى مستقبلًا تكون باستخدام خادم وقاعدة بيانات خاصة بدل الاستضافة الثابتة.
- تم ضبط حد أقصى للمحاولات المتتالية (20 محاولة) مع قفل مؤقت 10 ثوانٍ.
